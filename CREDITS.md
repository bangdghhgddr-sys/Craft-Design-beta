## Fonts

Craft Design does not bundle or automatically load third-party font files. The app uses the device's default system font until a user imports a font file (`.ttf`, `.otf`, `.woff`, or `.woff2`). Users are responsible for ensuring that imported fonts are properly licensed for their intended use.

## Brushes

The seven brush-tip images included with this build were extracted from an original hand-drawn brush sheet supplied by the developer, Enad. They are included as PNG assets for use inside Craft Design.
